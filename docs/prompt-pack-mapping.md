# Which prompt produced which module

The pack is four prompts and a checklist. This is where each landed.

## Prompt 1 — "Ask for the engine"

| Requirement from the prompt | Where it lives |
| --- | --- |
| "Take a single niche as its input" | `niche.py`, `stations/s1_niche.py` |
| "Build the complete interior to print-ready spec" | `stations/s2_interior.py`, `render/interior.py` |
| "Run a quality check that can FAIL the build and stop it" | `gates/g2_substance.py`, `errors.GateFailure`, `run/pipeline.py` |
| "Generate the cover wrap at the exact trim, bleed and spine width for the final page count" | `spec/kdp.cover_geometry`, `stations/s3_cover.py` |
| "Produce the full listing pack" | `stations/s4_listing.py` |
| "Deterministic where it can be… code, not prose, for anything countable" | `spec/kdp.py`, `content/rng.py`, ReportLab invariant mode, `naming.py` |
| "Every stage writes real files to /output/\<slug\>/" | `run/context.py`, `run/manifest.py` |
| "Never let the same step both produce and approve an artifact" | `gates/base.GateInput` — gates receive paths, not objects |
| "Ask me every clarifying question you need" | The interview, answered once and stored in `config.py` / `examples/engine.yaml` |

## Prompt 2 — "Make it prove itself"

*"Run the engine end to end on one real example and show me every artifact."*

```bash
kdp build examples/gratitude-new-mothers.yaml && kdp show output/<run>
```

*"What will break first when I run it fifty times?"* — the honest answer is in
[`docs/known-limits.md`](known-limits.md).

## Prompt 3 — "The quality gate"

Run as a separate pass from the one that built the book. Each of its six
criteria is a check in `gates/g2_substance.py`:

| Prompt 3 | Check |
| --- | --- |
| Padding | `padding`, `value_content_share` |
| Repetition | `repetition_exact`, `repetition_near_duplicate` |
| Promise | `promise_numbers`, `promise_kept` |
| Value | `value_no_empty_content_pages`, `content_reaches_the_page` |
| Errors | `errors_placeholders`, `errors_format_verification` |
| Completeness | `completeness_front_matter`, `completeness_back_matter`, `completeness_title_page`, `completeness_copyright`, `completeness_page_numbers` |

"Score each PASS or FAIL with a one-line reason. Any FAIL fails the gate" is
`GateReport.enforce()`.

## The stage checklist

| Checklist item | How the engine enforces it |
| --- | --- |
| "Name the actual demand signal — not a hunch" | `g1_niche.demand_evidence_named` |
| "Checked it for trademark or brand exposure" | `g1_niche.trademark_checked`, `trademark_clear` |
| "Anything countable was generated by code and verified by code" | `spec/kdp.py` + `g3_print` re-measuring the PDFs |
| "Page count landed on purpose, not by accident" | `g3_print.landed_on_target` |
| "A separate pass graded it and could have failed it" | `g2_substance`, reading the PDF from disk |
| "Spine width recomputed from the page count of the interior file that actually exists" | `stations/s3_cover.py` reads `pdf_page_count(interior)`; `g3_print.spine_recomputed_from_real_file` |
| "7 keywords, no slot wasted repeating title words" | `stations/s4_listing._keywords` |
| "It typed from the listing file, not from memory" | `upload/plan.py` is built from `listing.json` |
| "It read the form back before submitting" | `playwright_driver.UploadRun._read_back` |
| "It stopped at Publish" | `FORBIDDEN_ACTIONS`, `assert_not_forbidden` |
| "You opened the real PDF… and read the listing as a stranger" | `stations/s6_review.py` — written for you, never ticked for you |
| "Track how often a gate actually fails something" | `gates/base.record_gate_result`, `kdp gates` |
